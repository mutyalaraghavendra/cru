# Krousty Korner Website

A responsive restaurant website built from the supplied Krousty Korner branding and food images.

## Files
- `index.html` — main website
- `styles.css` — responsive styling and animations
- `script.js` — menu filters and shopping cart
- `assets/` — supplied logo and food images

## Run locally
Open `index.html` in a browser.

For a local server:
```bash
python -m http.server 8000
```
Then visit:
http://localhost:8000

## Deploy
Upload the whole `krousty-korner-website` folder to your hosting provider, keeping the `assets` folder beside `index.html`.

## Important
The checkout button is a front-end demo. Connect it to your real ordering provider/payment flow before accepting online orders.
